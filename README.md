# Демо: страница цен garant-ic.ru с новыми блоками

Статическая копия страницы `price.php` с блоками «Получить расчёт» и «Подобрать комплект» и формой заявки.
Заявки никуда не отправляются: `form_2.php` здесь заменён заглушкой `api/form.js`, которая только отвечает «принято».
Страница закрыта от поисковиков (`noindex`).

## Как выложить на Vercel

1. Создать на GitHub новый репозиторий и загрузить в него содержимое этой папки (`index.html`, `css/`, `js/`, `img/`, `inc/`, `api/`, `vercel.json`).
2. На vercel.com: Add New → Project → выбрать репозиторий.
3. Framework Preset: **Other**, Build Command и Output Directory — пустые (сборки нет), Root Directory — корень репозитория.
4. Deploy. Страница откроется по адресу `https://<проект>.vercel.app/` (и `/price.php`).

## Локальная проверка

Любой статический сервер из этой папки, например `npx serve .` — страница и модалка работают, но отправка формы
локально покажет ошибку: заглушка `api/form.js` работает только на Vercel (или через `vercel dev`).
